# Lastenlupalappu ulkomaille

Täytettävä ja tulostettava huoltajan lupatodistus lapsen lomamatkalle ulkomaille.
Pohjautuu Ulkoministeriön ohjeistukseen ([um.fi/lapselle-huoltajien-lupa-lomamatkalle](https://um.fi/lapselle-huoltajien-lupa-lomamatkalle)).

## Käyttö

**Vaihtoehto A — suoraan selaimessa, ei latauksia:**

Avaa lomake valmiiksi julkaistuna osoitteessa **[anahill.github.io/lastenlupalappu-ulkomaille](https://anahill.github.io/lastenlupalappu-ulkomaille/)**. Sivu toimii identtisesti kuin lokaali tiedosto — mikään täytetty tieto ei lähde minnekään, se pysyy vain oman selaimesi paikallisessa muistissa (ks. alla).

**Vaihtoehto B — lataa tiedosto omalle koneelle:**

1. Lataa [lupatodistus.html](lupatodistus.html) omalle koneelle (GitHubissa "Raw"-painike → tallenna sivu, tai lataa koko repo napista "Code" → "Download ZIP").
2. Avaa tiedosto suoraan selaimessa (kaksoisklikkaus riittää — ei vaadi internetyhteyttä).
3. Täytä kentät: lapsen tiedot, matkan tiedot sekä huoltajien tiedot ja allekirjoitukset.
4. Tulosta sivu (nappi "Print") tai tallenna PDF:ksi selaimen tulostusvalikosta.

Sivu toimii täysin selaimessa eikä lähetä mitään tietoja verkkoon — kaikki täytetty tieto pysyy omalla koneella. Täytetyt kentät tallentuvat automaattisesti selaimen paikalliseen muistiin (`localStorage`) tällä laitteella, niin lomake on edelleen täytettynä kun avaat tiedoston uudelleen. Tiedot pysyvät tallessa siihen asti, kun painat "New (clear saved data)" -nappia tai tyhjennät selaimen selaushistorian/sivustotiedot.

## Muista matkalle

- Pidä lupatodistus lapsen oman passin mukana koko matkan ajan.
- Näytä se lentoyhtiölle tai rajaviranomaisille pyydettäessä.
- Tarkista kohdemaan omat vaatimukset ennen matkaa, koska ne vaihtelevat maittain.
- Jos vain toisella huoltajalla on huoltajuus, liitä mukaan kopio huoltajuuspäätöksestä.

# Child Travel Consent Letter

A fillable, printable parental consent letter for a child's holiday travel abroad.
Based on guidance from the Finnish Ministry for Foreign Affairs ([um.fi/lapselle-huoltajien-lupa-lomamatkalle](https://um.fi/lapselle-huoltajien-lupa-lomamatkalle)).

**Option A — use it directly in your browser, no download needed:**

Open the form at **[anahill.github.io/lastenlupalappu-ulkomaille](https://anahill.github.io/lastenlupalappu-ulkomaille/)**. It works exactly like the local file — nothing you type is sent anywhere; it only stays in your browser's local storage (see below).

**Option B — download the file to your own computer:**

1. Download [lupatodistus.html](lupatodistus.html) (GitHub's "Raw" button → save page, or "Code" → "Download ZIP" for the whole repo).
2. Open the file directly in a browser (just double-click it — no internet connection required).
3. Fill in the child's, travel, and guardians' details, then print or save as PDF.

Either way, the page runs fully offline — nothing is sent over the network. Entered values are saved to this browser's local storage on this device, so the form stays filled in next time you open the file, until you click "New (clear saved data)" or clear the browser's site data.
