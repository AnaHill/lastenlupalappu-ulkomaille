# Lastenlupalappu ulkomaille

Täytettävä ja tulostettava huoltajan lupatodistus lapsen lomamatkalle ulkomaille.
Pohjautuu Ulkoministeriön ohjeistukseen ([um.fi/lapselle-huoltajien-lupa-lomamatkalle](https://um.fi/lapselle-huoltajien-lupa-lomamatkalle)).

## Käyttö

1. Avaa [lupatodistus.html](lupatodistus.html) suoraan selaimessa (kaksoisklikkaus riittää).
2. Täytä kentät: lapsen tiedot, matkan tiedot sekä huoltajien tiedot ja allekirjoitukset.
3. Tulosta sivu (nappi "Print") tai tallenna PDF:ksi selaimen tulostusvalikosta.

Sivu toimii täysin selaimessa eikä lähetä mitään tietoja verkkoon — kaikki täytetty tieto pysyy omalla koneella. Täytetyt kentät tallentuvat automaattisesti selaimen paikalliseen muistiin (`localStorage`) tällä laitteella, niin lomake on edelleen täytettynä kun avaat tiedoston uudelleen. Tiedot pysyvät tallessa siihen asti, kun painat "New (clear saved data)" -nappia tai tyhjennät selaimen selaushistorian/sivustotiedot.

## Muista matkalle

- Pidä lupatodistus lapsen oman passin mukana koko matkan ajan.
- Näytä se lentoyhtiölle tai rajaviranomaisille pyydettäessä.
- Tarkista kohdemaan omat vaatimukset ennen matkaa, koska ne vaihtelevat maittain.
- Jos vain toisella huoltajalla on huoltajuus, liitä mukaan kopio huoltajuuspäätöksestä.

# Child Travel Consent Letter

A fillable, printable parental consent letter for a child's holiday travel abroad.
Based on guidance from the Finnish Ministry for Foreign Affairs ([um.fi/lapselle-huoltajien-lupa-lomamatkalle](https://um.fi/lapselle-huoltajien-lupa-lomamatkalle)).

Open [lupatodistus.html](lupatodistus.html) in a browser, fill in the child's, travel, and guardians' details, then print or save as PDF. The page runs fully offline — nothing is sent over the network. Entered values are saved to this browser's local storage on this device, so the form stays filled in next time you open the file, until you click "New (clear saved data)" or clear the browser's site data.
